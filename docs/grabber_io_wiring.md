# Grabber I/O wiring — EL2521 → Xtium-CL MX4 (line-scan sync)

How the line-trigger / sync wires up between the Beckhoff motion side and the
Teledyne capture side. Status: design (2026-06), not yet wired.

## The big picture — read this first

- **EXSYNC (the camera's line trigger) is generated by the grabber and sent to
  the camera over the Camera Link cable (CC1).** You do **NOT** wire anything from
  the I/O cable to the camera. The I/O cable only feeds the grabber the *pacing
  source* (what tells it when to clock each line) + optional strobe.
- So the chain is: **EL2521 (RS-422 A/B) → grabber J1 I/O → grabber makes EXSYNC →
  camera over Camera Link.**

## Parts

- **Camera:** Piranha HS-80-08K80-00-R (Camera Link, MDR-26).
- **Grabber:** Teledyne **Xtium-CL MX4** (SDR-26 Camera Link in; RS-422 I/O).
- **I/O cable:** Teledyne **`OR-YXCC-27BE2M1`** — DH40-27S plug → ~2 m **blunt end
  (flying leads)**; plugs into grabber **J1 (DH60-27P)** on the bracket. (J4 is an
  internal 26-pin header with the *same* signals — use J1.) Aftermarket equivalent:
  Donghoo Tech "Dalsa Xtium DH40-27S" cable.
- **Pacing source:** Beckhoff **EL2521-0000** pulse-train output terminal —
  **RS-422 differential, 5 V level, two channels (A/B), incremental-encoder
  simulation**, 0…500 kHz. Driven by `xylod` (the line-trigger frequency follows
  the speed curve). RS-422 ↔ RS-422 with the grabber = **no level conversion**.

## Recommended path — position-locked (encoder simulation) [best for 96-stage TDI]

Set the EL2521 to **incremental-encoder simulation** → it outputs A/B quadrature.
Feed that into the grabber's RS-422 **shaft-encoder** inputs (these pins are
confirmed from the MX4 manual):

| EL2521-0000 output | → | Xtium-CL MX4 J1 pin |
|---|---|---|
| Output **A+** | → | **Pin 3** (Shaft Encoder Phase A+) |
| Output **A−** | → | **Pin 2** (Shaft Encoder Phase A−) |
| Output **B+** | → | **Pin 6** (Shaft Encoder Phase B+) |
| Output **B−** | → | **Pin 5** (Shaft Encoder Phase B−) |
| 0 V / signal GND | → | grabber GND |

- The EL2521's two RS-422 output pairs (A+/A−, B+/B−): read the exact
  **connection-point numbers off the EL2521 terminal diagram** (printed on the part).
- Sapera: `CORACQ_PRM_SHAFT_ENCODER_ENABLE = true` (dual phase). The grabber's
  pulse-multiply / pulse-drop / direction features then shape EXSYNC.

## Alternative — trigger-paced (one line per pulse) [simpler]

Set the EL2521 to plain pulse output; wire **Output A (A+/A−) → the grabber's
External (line) Trigger input** (RS-422). Sapera:
`CORACQ_PRM_EXT_LINE_TRIGGER_ENABLE = true`.

⚠️ The **External-Trigger input pin is board-revision-dependent** — the MX4 manual
has **Table 30 (Rev A2)** and **Table 31 (Rev A1)**, "J1 & J4 Connector Signals",
p. 86. Check your board rev and use the matching table. (The shaft-encoder pins
above are confirmed; the trigger pin is the one that moves — so the encoder path
is the fully-specified one.)

## Electrical notes

- **RS-422 ↔ RS-422**, 5 V differential both ends — direct wire, no opto, no 24 V.
- **Termination:** RS-422 wants ~120 Ω at the receiver; the grabber's RS-422 input
  typically provides it (EL2521 min load = 120 Ω). Confirm it's terminated once.
- The grabber offers **5 V / 12 V power-out on J1** if a small device ever needs it.
- The pin↔wire-colour map ships on the **Product Notice in the cable bag** — use it
  with the rev-correct J1 table.

## Identifying the wires (blunt-end cable) — beep-test method

You only need **5 wires** (pins 3, 2, 6, 5 + a GND) out of the 27. Fastest, most
trustworthy way to find them:

1. Check the cable bag for Teledyne's **wire-colour → pin sheet** ("Product
   Notice"). Use it as a hint, not gospel.
2. **Verify with a multimeter on continuity.** The DH40-27S plug has **pin numbers
   molded on it**. Probe a known pin, then touch each blunt wire until it beeps:
   - **Pin 3 → A+**, **Pin 2 → A−**, **Pin 6 → B+**, **Pin 5 → B−**, plus a **GND** pin.
3. **Label each wire as you find it** (heat-shrink/tape: "A+ p3", "B+ p6", …), then
   **cut back and tape off the other ~22**. Your 27-core cable becomes a 5-wire harness.
4. **Confirm pin-1 orientation** (molded triangle/notch on the plug) so you're
   counting pins the same way the manual's J1 table does — otherwise pin 3 could be
   mirrored.

This is mandatory for aftermarket cables (Donghoo etc.) — their colour code won't
match Teledyne's. The beep test is colour-agnostic, so it always works.

## Behaviour nuance

Encoder-sim locks the line trigger to **commanded** motion (the drawn curve), not
*measured* shaft position. For the precise harmonic servo that's effectively the
same — and it's exactly **WYSIWYG**: line rate follows the artist's curve. For true
measured-position lock, add a real shaft encoder later; the EL2521 sim is the clean
default.
